# Protocol Contract: vault-audio Scheme

**Scheme**: `vault-audio://`
**Process**: Main Process (Protocol Handler) ↔ Renderer Process (HTML5 `<audio>`)
**Security Privileges**: `standard: true`, `secure: true`, `supportFetchAPI: true`, `stream: true`

---

## 1. Scheme Registration (Before App Ready)

Before the `app.ready` / `app.whenReady()` event fires in Electron Main:

```typescript
protocol.registerSchemesAsPrivileged([
  {
    scheme: 'vault-audio',
    privileges: {
      standard: true,
      secure: true,
      supportFetchAPI: true,
      stream: true,
    },
  },
]);
```

---

## 2. Request Contract

### URI Format
```text
vault-audio://stream/<relative-file-path>
```

- **Authority**: `stream`
- **Path**: Path relative to the audio vault root (e.g., `recordings/uuid.wav` or `imports/uuid.mp3`).
- **Example**: `vault-audio://stream/recordings/d3b07384-d113-46d4-a957-c6b1297e615e.wav`

### Request Headers
Standard HTTP/fetch headers generated by the Chromium media engine:
- `Range`: `bytes=<start>-<end>` (optional; present during scrubbing/seeking).
- `Accept`: `audio/*`

---

## 3. Response Contract

### Success Responses

#### Full Content (Status 200 OK)
Returned when no `Range` header is provided.
- **Status**: `200 OK`
- **Headers**:
  - `Content-Type`: `audio/wav`, `audio/mpeg`, `audio/mp4`, `audio/ogg`, `audio/flac` (determined by extension/file)
  - `Content-Length`: `<total_file_bytes>`
  - `Accept-Ranges`: `bytes`
- **Body**: Complete audio binary stream.

#### Partial Content (Status 206 Partial Content)
Returned when a `Range` header is present (scrubbing/seeking).
- **Status**: `206 Partial Content`
- **Headers**:
  - `Content-Type`: `audio/...`
  - `Content-Range`: `bytes <start>-<end>/<total>`
  - `Content-Length`: `<chunk_length>`
  - `Accept-Ranges`: `bytes`
- **Body**: Requested byte range slice.

### Error Responses

#### 404 Not Found
Returned when the requested audio file does not exist on disk.
- **Status**: `404 Not Found`
- **Body**: Empty or error description string.

#### 403 Forbidden
Returned when path traversal is detected (the resolved path attempts to escape the `audio_vault` boundary).
- **Status**: `403 Forbidden`
- **Body**: "Access denied: Path traversal detected".
